# G⁵ Portal

麗澤高等学校 5年G組 フリー自作ツール・副教材配信ポータル。

## 機能

- **無料自作ツール** … `pages/` 配下（1機能 = 1ディレクトリ = 1ページ）
- 文字系: 文字数カウント · 文字拡大鏡 · パスワード生成 · 暗号化・復号 · QR
- 時間 / 乱数 / 色: タイマー/SW · コイン・サイコロ・抽選 · カラーピッカー · デジタル時計
- 共有: 画面シェア (WebRTC) · ファイル共有 (WebRTC)
- ユーティリティ: 電卓 · OCR文字認識 · グループ分け · IPアドレス情報 · 速度チェッカー
- **MultiQuiz** · **副教材**（PDF 配置枠）
- **統一メニュー** … ラジアル + ハンバーガー（FAB）
- **時間・天気連動デザイン** … Open-Meteo API + 各天気ごとのCSS/JSアニメーション

## WebRTC 共有

- シグナリング: PeerJS クラウド（`0.peerjs.com`）
- STUN: Google public STUN
- 画面シェア: 共有側 `getDisplayMedia` → 視聴側がルーム ID / URL / QR で接続
- ファイル共有: 送信側がファイル選択後に共有開始 → 受信側が接続してダウンロード
